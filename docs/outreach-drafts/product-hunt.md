### Description

Deep Breathing Exercises is a paced-breathing pacer that runs in a browser tab. Press start and follow the orb through inhale, hold, exhale and hold. Five patterns: box breathing, 4-7-8, coherent at 5.5, the physiological sigh and Wim Hof rounds. Phase length adjusts from three to eight seconds, sessions run one to five minutes. No download, no account, no paid tier. Available in English, Spanish, German, French, Japanese and Portuguese, and embeddable in any page.

### First comment (maker comment)

I built this because most breathing tools are apps, and an app is the wrong shape for something you need for ninety seconds before a meeting. Installing is more friction than the exercise.

So it is a web page. No signup, no paywall, nothing to delete afterwards. Five patterns, adjustable pace, six languages, and an embed if you want the pacer inside your own page.

The thing I would most like feedback on is the pacing cue itself. Some people follow the orb, some prefer the numbers, and I have not found a version that suits both. If you try it, tell me which one you followed.

Abi
